Exactly one funny line for make.fun's "One Line, Big Laugh" bounty ($2, $1 for first place and $1 for second) — a single joke that lands on a cold read, with no setup notes and no explanation.

> I told my boss I thrive under pressure. He moved my desk under the air conditioner.

The program (`main.ts`, Node 22+) writes that single line — 83 characters — to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
node main.ts
```
